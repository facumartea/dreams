           Trabajo práctico de Integración – TP Final
Consigna General:
Se debe desarrollar un sitio y la imagen corporativa de una marca de producto y producto a elección,
la marca debe ser de fantasía, su objetivo es presentar los productos de forma que estos sean
vendibles y que se apliquen herramientas de programación y diseño. El sitio debe ser atractivo y
funcional.

Objetivo:
El objetivo del trabajo es el de poder aplicar los conceptos de diseño web, programación Javascript , API
y SQL trabajados durante el año, así como ciclos, funciones, condicionales, operadores lógicos, etc
incorporados en un sitio web o app específico. Así como herramientas de diseño gráfico y editorial.
​
Criterios de Diseño:
Además de la programación y la documentación, el trabajo deberá reflejar los principios básicos de
diseño vistos durante el año.​
Diseño de un logo: Simple, como máximo 3 colores en PNG.​
Coherencia visual: uso de una paleta cromática definida y constante en todas las páginas o pantallas.​
Tipografía: aplicación de jerarquías tipográficas claras (títulos, subtítulos, cuerpo de texto) y
combinación de fuentes acorde al tema del sitio o app.​
Navegación clara: botones y enlaces visibles, menús.​
Identidad visual: el diseño debe reflejar el tema del sitio o app de forma atractiva y creativa.​
Elementos visuales: integración de imágenes, íconos, o ilustraciones con criterio estético y funcional.


Criterios de Programación a considerar - Los estudiantes deben poder:
     ●​ Leer y escribir código adecuadamente.
     ●​ Utilizar adecuadamente la documentación.
     ●​ Mostrar capacidad de resolución y autonomía

Especificación de requerimientos:
●​ El grupo de trabajo no puede ser mayor a 3 alumnos, pudiendo interrogar el profesor al /los
    alumno/s de los que no quede claro su aporte al trabajo.
●​ Fecha de entrega previa 30 de octubre.
●​ Fecha de entrega final 12 de noviembre.
●​ Se puede optar entre un sitio completo HTML/CSS/Javascript, aplicando/consumiendo una API o
    una app Flask, utilizando HTML/CSS/JS y Base de datos (SQLite), o un sitio web HTML/CSS/JS
    consumiendo una API de Python.
●​ En el caso de desarrollar un sitio web debe tener un mínimo de 4 páginas, implementando todo lo
    visto durante el año. Debe implementarse si o si Javascript, carousel, web semántica y diseño
    adaptable a las pantallas (responsive)
●​ En el caso de la app no hay un mínimo de páginas, depende del proyecto solicitado.

Documentación:
●​ Pseudocódigos y/o Wireframe (diseño de las conexiones de las páginas, utilizando una herramienta
   ad-hoc o en mano muy prolijo).
●​ Manual de uso (Como se usa el software que diseñaron y construyeron)
●​ Diseño de base de datos (en caso de usarse una BD)
●​ Link a la API. Explicación de su uso (más allá de la implementación)
