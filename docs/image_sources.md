# Fuentes visuales

El proyecto utiliza imágenes externas para que los productos se vean como una tienda real. Las referencias de perfumes y fotografía se localizaron mediante búsqueda web / búsqueda de imágenes.

## Referencias verificadas durante el desarrollo

- Armani Beauty: colección de fragancias y organización por familias olfativas.
- Dior Argentina: información de Sauvage, notas y estructura de fichas de producto.
- Chanel: referencias visuales de Bleu de Chanel y Coco Mademoiselle.
- Creed: referencia visual de Aventus y presentación premium.
- Unsplash: fotografías de perfumes utilizadas como imágenes editoriales y fallback.

En una tienda comercial real se debe comprobar la licencia de cada fotografía y contar con autorización para usar imágenes de producto de marcas registradas. Este proyecto es académico.
