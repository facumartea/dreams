DREAMS - INSTALACION LOCAL

1. Instalar Node.js 20 o superior y habilitar Corepack.
2. Copiar .env.example como .env y completar un Supabase de desarrollo.
3. Aplicar supabase/migrations con Supabase CLI en ese entorno.
4. Ejecutar: pnpm install --frozen-lockfile
5. Ejecutar: pnpm start
6. Abrir: http://localhost:3000

VERIFICACION
- pnpm run check
- pnpm test
- pnpm audit --prod

ADMIN
- Correo y clave: ADMIN_EMAIL y ADMIN_PASSWORD del entorno.
- Panel: http://localhost:3000/admin
- No existe una clave predeterminada en el repositorio.

RAILWAY
- Usar las variables de .env.example como secretos del servicio.
- No crear Volume: Supabase conserva los datos.
- Verificar /api/health y los flujos críticos después del deploy.

Nunca subir .env, node_modules ni SUPABASE_SECRET_KEY.
