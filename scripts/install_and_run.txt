DREAMS - INSTALACION Y VERIFICACION LOCAL (ENTREGA 2026)

Requisitos: Node.js 24.x y pnpm 11.19.0 mediante Corepack.
Desde la raiz, tambien en una extraccion sin .git:

corepack pnpm install --frozen-lockfile
corepack pnpm run check
corepack pnpm run check:functions
corepack pnpm test
corepack pnpm run build:pages
corepack pnpm run build:official

Estos checks y builds usan fixtures y no requieren secretos reales ni publican.

ARRANQUE CONECTADO DE DESARROLLO
1. Copiar .env.example como .env y completar un Supabase de desarrollo.
2. Revisar/aplicar supabase/migrations solo en ese proyecto, sin resets/seeds.
3. Ejecutar: corepack pnpm start
4. Abrir http://localhost:8080 (o el PORT configurado).

ADMIN
Panel: http://localhost:8080/admin
Usar una cuenta autorizada existente. El arranque no crea administradores.
No existe una clave predeterminada y no se cambia ninguna credencial para QA.

HOSTING
Unica oficial autorizada: https://dreams-perfumes.pages.dev/
Pages y backend privado Cloudflare; no desplegar previews u otros sitios.
La publicacion requiere las guardas y QA descritas en CURRENT_STATE.md.
Railway es un antecedente historico, no un destino de esta entrega.

Documentacion completa: docs/entrega-2026/INDICE.md y README.md.
